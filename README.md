# 京升学 · 北京升学政策查询（非官方）

北京幼儿园 → 小学 → 初中 → 高中/中职 → 大学（在京高考资格）的入学条件整理，每条附官方原文链接。政策核对日期 2026-10-12。

- 在线：https://temptation2017.github.io/jingshengxue/
- 技术：Next.js 14（App Router, 静态导出）+ TypeScript + Tailwind
- 数据：`data/policies.json`（12 条官方政策）、`data/stages.json`（分学段字段表）
- 开发：`npm ci && npm run dev`；构建：`npm run build` → `out/`

本站非官方，以市、区教委及招生单位当年正式文件为准，不承诺录取。
